# لقطة شوبنج | Lokta Shopping

واجهة متجر إلكتروني عربية باتجاه RTL مبنية باستخدام React وVite وReact Router وTailwind CSS وLucide React. المشروع Front-End فقط، والبيانات تجريبية.

## المتطلبات
- Node.js 18 أو أحدث
- npm

## التثبيت والتشغيل
```bash
npm install
npm run dev
```
سيظهر رابط محلي في الطرفية (غالبًا `http://localhost:5173`).

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```

## أهم المجلدات
- `src/data/products.js`: بيانات المنتجات والأقسام والصور والأسعار.
- `src/context/ShopContext.jsx`: حالة السلة والمفضلة والتنبيهات.
- `src/components/`: الهيدر والفوتر وبطاقات المنتجات والمكونات المشتركة.
- `src/pages/`: الصفحة الرئيسية، قائمة المنتجات والعروض، تفاصيل المنتج، السلة، إتمام الطلب، المفضلة، السياسات وصفحات المعلومات.
- `src/services/`: مكان مخصص لإضافة طبقة API مستقبلًا.
- `src/utils/storage.js`: قراءة وكتابة البيانات المحلية.

## الوظائف الموجودة
- تنقل داخلي بواسطة React Router.
- بحث بالاسم أو الماركة أو القسم، وفلاتر القسم والماركة والسعر والتوفر، والترتيب حسب السعر أو الأحدث أو الخصم.
- إضافة للسلة وتعديل الكميات وحذف المنتجات وحساب الإجمالي والتوفير.
- مفضلة محفوظة محليًا.
- تفاصيل المنتج ومواصفاته وزر مشاركة الرابط ورابط واتساب تجريبي.
- نموذج Checkout مع تحقق أساسي من الحقول وإنشاء رقم طلب محلي تجريبي وصفحة نجاح.
- صفحات من نحن، تواصل معنا، الأسئلة الشائعة، الخصوصية، الشحن، الاستبدال والاسترجاع، و404.
- واجهة متجاوبة للموبايل والتابلت والكمبيوتر.

## ملاحظات مهمة
- لا يوجد Backend أو قاعدة بيانات أو بوابة دفع أو خدمة بريد أو إدارة مخزون حقيقية.
- الطلب التجريبي لا يُرسل إلى المتجر. معلومات الاتصال ورقم واتساب والتقييمات والأسعار ومصاريف التوصيل أمثلة قابلة للتعديل.
- السلة والمفضلة محفوظتان في `LocalStorage`، والطلب الأخير في `sessionStorage`؛ هذه الوسائل ليست بديلًا آمنًا لقاعدة بيانات.
- الصور والخط العربي تأتي من روابط خارجية، لذا يلزم اتصال بالإنترنت لعرضها. يوجد بديل للصورة عند فشل تحميل صور المنتجات.
- قبل الإطلاق التجاري، استبدل البيانات التجريبية، وأضف API في `src/services/`، ونظام طلبات ومصادقة ودفع مناسبًا، وراجع سياسات المتجر.


## حل مشاكل التشغيل

1. تأكد من تثبيت Node.js إصدار 20 أو أحدث.
2. افتح Terminal داخل مجلد المشروع الذي يحتوي على `package.json`.
3. نفّذ `npm install` وانتظر حتى يكتمل تنزيل الحزم.
4. نفّذ `npm run dev` وافتح عنوان localhost الذي يظهر في الطرفية.
5. إذا كانت هناك نسخة قديمة من الحزم، احذف `node_modules` و`package-lock.json` ثم نفّذ `npm install` من جديد.

تم تثبيت إصدارات الحزم في `package.json` لتجنب تغيّر الإصدارات تلقائيًا.
